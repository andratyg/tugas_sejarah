# **App Name**: IlmuNesia

## Core Features:

- Dynamic Navigation Bar: Fixed navbar with adaptive scroll behavior (show/hide with animation) and a toggle for dark/light mode preference that persists.
- Interactive Hero Section: Full-screen hero section featuring a prominent title, subtitle, a call-to-action button, and an animated scroll indicator.
- Vertical Timeline Learning Path: Engaging display of learning materials arranged along a vertical timeline, with interactive cards positioned alternately right and left.
- Interactive Material Details Pop-up: Display comprehensive material details including illustrations, extended descriptions, key takeaways, and clickbable references in a modal window.
- AI-Powered Content Summarization Tool: Provide a tool within the material detail pop-up to generate a concise summary of the learning material's key points for quick comprehension.
- Project Showcase Cards: Dedicated section displaying project cards, each with a title, brief description, preview image, and a button to view detailed project information in a pop-up.
- Responsive & Adaptive Layout: Ensure the website is fully responsive, adapting the layout (e.g., timeline cards to a single column, navbar to a hamburger menu) across desktop, tablet, and mobile devices.

## Style Guidelines:

- Light Mode Primary: Rich Amber-Brown (#805A13) to represent knowledge and elegance.
- Light Mode Background: Subtle Warm Off-White (#F9F8F4) for a clean, unobtrusive canvas.
- Light Mode Accent: Warm Terracotta-Red (#D1897A) for interactive elements and emphasis, offering gentle contrast.
- Dark Mode Background: Deep charcoal (#1e1e1e) for low-light comfort.
- Dark Mode Navbar: Nearly black (#121212) with a blurred glass effect for depth.
- Dark Mode Text: Soft light gray (#e5e5e5) to minimize eye strain.
- Dark Mode Accent & Timeline: Vibrant gold (#d4a017 and #b8963d for timeline) for interactive elements and highlights, aligning with the primary light mode hue.
- Headlines: 'Poppins' (sans-serif) for a contemporary, precise feel.
- Body Text: 'Inter' (sans-serif) for neutral, highly legible content.
- Minimalist, line-art style icons for toggle buttons, scroll indicators, and material highlights to maintain a clean aesthetic.
- Clean, minimalist, and spacious layout achieved using CSS Flexbox and Grid for precise alignment and responsive element distribution.
- Smooth scrolling, navbar slide transitions, material card fade/slide animations on scroll, subtle hover effects (grow, soft shadow), and scale/fade animations for pop-ups to enhance user experience.
